# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's
[security advisories](https://github.com/jcschuster/AtpClient/security/advisories/new)
for this repository, or by email to <johannes.schuster@uni-bamberg.de>. Do not
open a public issue for a vulnerability.

You will get an acknowledgement within a week. Fixes are released as a new
version on Hex with an entry in `CHANGELOG.md`; the advisory is published once
that version is out.

## Supported versions

Only the latest release on [Hex](https://hex.pm/packages/atp_client) receives fixes.
